ATUALIZACAO 2 - PUBLICACOES NO BANCO

Pare os dois servidores antes de copiar: no terminal do npm, Ctrl+C; no terminal da API, Ctrl+C.
Faca backup das pastas web e api antes de substituir.
Extraia este ZIP na pasta do projeto, preservando a estrutura web/ e api/.
Aceite substituir os arquivos.

Depois, no terminal da API:
  cd /d "C:\Users\edicc\Downloads\feira_tech_test-main\api"
  php artisan migrate
  php artisan config:clear
  php artisan serve --host=127.0.0.1 --port=8000

Em outro terminal:
  cd /d "C:\Users\edicc\Downloads\feira_tech_test-main\web"
  npm run dev

O feed agora busca publicacoes na API e o botao Publicar salva no PostgreSQL.
Se a IA estiver sem chave ou indisponivel, o texto fica pendente no banco em vez de desaparecer.
